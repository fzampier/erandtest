# Reproducibility Inventory

This inventory covers the active V9 manuscript only. Every table, figure, CSV,
and numerical support artifact used by `manuscript/e-RT_v9.tex` is generated by
committed code. Exploratory material lives under `explorations/` and is not
part of the active chain.

Run the full chain from the repository root:

```sh
make all
```

## Manually Reported Numerical Claims

The active manuscript numerical claims are drawn from generated table inputs or
the CSVs above:

- e-RTb baseline Type I error, power, and median crossing:
  `ertb_baseline_5000.csv`.
- e-RTe signal concentration and same-N head-to-head comparison:
  `erte_signal_concentration.csv` and `erte_head_to_head_2000.csv`.
- e-RTe/e-RTb adaptive tuning sensitivity:
  `erte_tuning_sensitivity_1000.csv`.
- e-RTb/e-RTe design-wager power and Type M summaries:
  `wager_policy_5000_same_n.csv`.
- e-RTc design-wager summaries: `ertc_wager_policy_1000.csv`.
- Binary over-betting stress results:
  `wager_asymmetry_binary_1000.csv`.
