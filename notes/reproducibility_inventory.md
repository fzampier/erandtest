# Reproducibility Inventory

This inventory covers the active V8 manuscript only. Every table, figure, CSV,
and numerical support artifact used by `manuscript/e-RT_v8.tex` is generated by
committed code. Exploratory scripts remain in `R/simulations/`, but exploratory
pilot CSV outputs are not part of the active chain.

Run the full chain from the repository root:

```sh
make all
```

## Manually Reported Numerical Claims

The active manuscript numerical claims are drawn from generated table inputs or
the CSVs above:

- e-RTb baseline Type I error, power, and median crossing:
  `ertb_baseline_5000.csv`.
- e-RTe signal concentration, operating characteristics, and head-to-head
  comparison: `erte_signal_concentration.csv`,
  `erte_operating_characteristics_2000.csv`, and
  `erte_head_to_head_2000.csv`.
- e-RTb/e-RTe design-wager power and Type M summaries:
  `wager_policy_1000_same_n.csv`.
- e-RTwr simple WR and composite endpoint summaries:
  `ertwr_sokolova_comparison_1000.csv` and
  `ertwr_composite_buysetest_300_250.csv`.
- e-RTc design-wager summaries: `ertc_wager_policy_1000.csv`.
- e-RTs design-wager, Type M, and Type S summaries:
  `erts_wager_policy_1000.csv`.
- e-RTs staggered-entry paragraph:
  `erts_staggered_entry_summary_1000.csv`.
- Binary over-betting stress results:
  `wager_asymmetry_binary_1000.csv`.
